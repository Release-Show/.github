# Release-Show/.github

The organization profile for [Release-Show](https://github.com/Release-Show).
`profile/README.md` is what GitHub shows on the organization page; `assets/`
holds its banner, the organization avatar and the logo.

The banner and avatar are rendered in
[`Release-Show/website`](https://github.com/Release-Show/website) by
`tools/render-og.sh` (sources: `tools/banner-render.html`,
`tools/avatar-render.html`). Re-render there and copy them here; do not edit
the PNGs by hand. The avatar is uploaded by hand at
`github.com/organizations/Release-Show/settings/profile`: GitHub has no API for it.
